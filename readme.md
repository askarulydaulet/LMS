# Мини-LMS: курсы, модули, задания, оценки, комментарии, импорт/экспорт
 
# Описание
OpenStudy — это современное веб-приложение для организации дистанционного обучения. Проект представляет собой полноценную экосистему, которая разделяет интерфейсы для Студентов и Преподавателей, обеспечивая удобное взаимодействие между ними.
Основная цель проекта — предоставить легковесную и быструю платформу, где студенты могут изучать лекции в видео-формате, а преподаватели — контролировать прогресс и оценивать практические работы. Система построена на архитектуре "Serverless Frontend", где в качестве базы данных для демонстрации используется LocalStorage и статические JSON файлы.
 
#Ключевые возможности
Для Студентов:
- Интерактивный дашборд: Просмотр личной статистики (активные курсы, завершенные задания, средний балл).
- Каталог курсов: Удобный поиск по доступным образовательным программам с фильтрацией в реальном времени.
- Учебный плеер: Просмотр видео-уроков с YouTube без перехода на сторонние ресурсы, изучение структуры модулей и дополнительных материалов.
- Система сдачи работ: Форма загрузки выполненных заданий (ссылки на GitHub/Google Drive) с возможностью добавления комментария для учителя.
- Контроль дедлайнов: Список ближайших задач с цветовой индикацией статуса.

Для Преподавателей:
- Аналитика курсов: Статистика по количеству записавшихся студентов, успешно сдавших работы и среднему баллу по группе.
- Панель проверки: Центр управления заданиями, где преподаватель видит все присланные работы, может перейти по ссылке студента и выставить оценку.
- Управление контентом: Интерфейс для просмотра и редактирования существующих курсов.

Общие функции:
- Ролевая модель: Автоматический редирект на нужный дашборд в зависимости от роли пользователя (Студент/Преподаватель).
- Восстановление пароля: Интеграция с сервисом EmailJS для отправки реальных кодов подтверждения на почту пользователя.
- Адаптивность: Полная поддержка работы на ноутбуках, планшетах и мониторах с высоким разрешением.
 
#Технологический стек
Проект реализован с использованием современных стандартов фронтенд-разработки без использования тяжелых фреймворков, что обеспечивает максимальную скорость работы:
- HTML5: Семантическая разметка для лучшей доступности.
- CSS3: Использование CSS Variables для тем оформления, Grid и Flexbox для построения сложных сеток (особенно в дашбордах).
- JavaScript (ES6+): Асинхронная загрузка данных через fetch, динамический рендеринг компонентов, управление состоянием через localStorage.
- Lucide Icons: Библиотека иконок для создания современного и чистого интерфейса.
- EmailJS API: Сервис для реализации почтовых уведомлений прямо из браузера.
- JSON: Формат хранения данных о курсах и пользователях.
